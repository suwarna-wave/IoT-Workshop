Core Concepts from Scratch

These are the concepts students must understand before copying any code.

1. Wi-Fi Modes on ESP Boards

ESP32 and ESP8266 have built-in Wi-Fi radios, making them suitable for IoT communication.

ModeMeaningSimple ExplanationIoT Use Case
StationSTAESP connects to an existing router like a phone or laptop.Cloud API, weather API, sensor upload
Access PointAPESP becomes its own Wi-Fi hotspot. Phone/laptop connects to ESP.Offline setup page, local control page
AP + StationAP+STAESP connects to router and also creates a hotspot.Configuration portal while staying online

Basic Wi-Fi Connection Pattern

#include <WiFi.h>   // ESP32
// For ESP8266 use: #include <ESP8266WiFi.h>

const char* ssid = "YourWiFiName";
const char* password = "YourPassword";

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nWiFi Connected!");
  Serial.print("IP Address: ");
  Serial.println(WiFi.localIP());
}
void loop() {}
Key idea: An IP address is the ESP board's address on the network. When the ESP hosts a web server, students will type this IP address into a browser.

2. HTTP Protocol

HTTP is the language used by browsers, APIs, and many IoT devices to exchange data.

Client ESP32 → HTTP Request → Server/API Client ESP32 ← HTTP Response ← Server/API Request = Method + URL + Headers + optional Body Response = Status Code + Headers + Body
MethodPurposeIoT ExampleHas Body?
GETRetrieve/read dataFetch weather, config, server statusNo
POSTSend/create dataUpload DHT11 reading to cloudYes
PUTReplace/update full dataUpdate device settingsYes
DELETERemove dataDelete old logNo
PATCHPartial updateChange only one valueYes
Status CodeMeaningWhat It Means for ESP
200 OKSuccessServer accepted the request.
201 CreatedCreatedPOST successfully saved data.
400 Bad RequestWrong requestCheck JSON body, header, or URL format.
401 UnauthorizedAuth requiredAPI key or token needed.
404 Not FoundURL not foundCheck endpoint spelling.
500 Server ErrorServer problemBackend failed; not always ESP's fault.

3. JSON for IoT

JSON is a lightweight text format commonly used to send IoT sensor data.

{
  "device_id": "esp32_001",
  "temperature": 28.5,
  "humidity": 65,
  "unit": "celsius"
}
Use ArduinoJson when:
Payload has multiple fields, nested objects, arrays, or should be reliable.
Use String concatenation only when:
Payload is very small, flat, and used for quick classroom testing.

Project 1 — Wi-Fi Scanner

Difficulty: Beginner · Hardware: ESP32/ESP8266 + USB only · Duration: 15 minutes

Objective

Scan available Wi-Fi networks nearby and print their SSID, RSSI signal strength, and encryption status to Serial Monitor.

Diagram Slot 1: Wi-Fi Scanner SetupInsert screenshot/photo here: ESP32 connected to laptop through USB, Serial Monitor open, nearby networks listed.

RSSI Signal Strength Guide

RSSI ValueSignal QualityMeaning
-30 dBm to -50 dBmExcellentVery close to router or strong signal.
-51 dBm to -67 dBmGoodStable for most IoT communication.
-68 dBm to -75 dBmWeakMay work, but expect packet loss or delays.
Below -75 dBmPoorMove closer to router or improve antenna position.

ESP32 Code

/* Day 2 Project 1: Wi-Fi Network Scanner */
#include <WiFi.h>

void setup() {
  Serial.begin(115200);
  delay(1000);
  WiFi.mode(WIFI_STA);
  WiFi.disconnect();
  delay(100);
  Serial.println("=== Wi-Fi Scanner Ready ===");
}

void loop() {
  Serial.println("\nScanning nearby Wi-Fi networks...");
  int networkCount = WiFi.scanNetworks();
  if (networkCount == 0) {
    Serial.println("No networks found.");
  } else {
    Serial.print(networkCount);
    Serial.println(" networks found:");
    Serial.println("----------------------------------------");
    for (int i = 0; i < networkCount; i++) {
      Serial.print(i + 1);
      Serial.print(". SSID: ");
      Serial.print(WiFi.SSID(i));
      Serial.print(" | RSSI: ");
      Serial.print(WiFi.RSSI(i));
      Serial.print(" dBm | Security: ");
      Serial.println(WiFi.encryptionType(i) == WIFI_AUTH_OPEN ? "Open" : "Encrypted");
      delay(10);
    }
    Serial.println("----------------------------------------");
  }
  WiFi.scanDelete();
  delay(10000);
}

ESP8266 Changes

// Replace:
#include <WiFi.h>
// With:
#include <ESP8266WiFi.h>
// Encryption check:
Serial.println(WiFi.encryptionType(i) == ENC_TYPE_NONE ? "Open" : "Encrypted");

Project 2 — Wi-Fi Connection with Reconnect Logic

Difficulty: Beginner · Hardware: ESP32 + USB only · Duration: 20 minutes

Objective

Connect ESP32 to a Wi-Fi router, print IP address, and keep checking connection status.

Why this matters: All upcoming HTTP, weather, web server, and DHT11 data-transfer projects depend on stable Wi-Fi.

ESP32 Code

/* Day 2 Project 2: ESP32 Wi-Fi Connection with Reconnect Logic */
#include <WiFi.h>

const char* ssid = "YourSSID";
const char* password = "YourPassword";
unsigned long lastCheckTime = 0;
const unsigned long checkInterval = 5000;

void connectToWiFi() {
  Serial.print("Connecting to Wi-Fi: ");
  Serial.println(ssid);
  WiFi.mode(WIFI_STA);
  WiFi.begin(ssid, password);
  int attempts = 0;
  while (WiFi.status() != WL_CONNECTED && attempts < 20) {
    delay(500);
    Serial.print(".");
    attempts++;
  }
  Serial.println();
  if (WiFi.status() == WL_CONNECTED) {
    Serial.println("Wi-Fi connected successfully!");
    Serial.print("IP Address: ");
    Serial.println(WiFi.localIP());
    Serial.print("Signal Strength: ");
    Serial.print(WiFi.RSSI());
    Serial.println(" dBm");
  } else {
    Serial.println("Wi-Fi connection failed. Check SSID/password.");
  }
}

void setup() {
  Serial.begin(115200);
  delay(500);
  connectToWiFi();
}

void loop() {
  if (millis() - lastCheckTime >= checkInterval) {
    lastCheckTime = millis();
    Serial.print("Uptime: ");
    Serial.print(millis() / 1000);
    Serial.println(" seconds");
    if (WiFi.status() != WL_CONNECTED) {
      Serial.println("Wi-Fi disconnected! Reconnecting...");
      WiFi.disconnect();
      WiFi.reconnect();
      delay(2000);
      if (WiFi.status() == WL_CONNECTED) {
        Serial.println("Reconnected!");
        Serial.println(WiFi.localIP());
      }
    } else {
      Serial.println("Wi-Fi status: Connected");
    }
  }
}

Common Mistakes

  • SSID and password are case-sensitive.
  • ESP32 works on 2.4 GHz Wi-Fi; some boards do not connect to 5 GHz-only networks.
  • If dots never stop printing, use a phone hotspot to test.

Project 3 — Live Weather Forecast using HTTP GET

Difficulty: Beginner-Intermediate · Hardware: ESP32 + Wi-Fi · Duration: 25 minutes

Objective

Fetch live weather text for a city using a public weather endpoint and print the response to Serial Monitor.

ESP32 → Wi-Fi Router → HTTP GET Request → Weather API → HTTP Response → Serial Monitor

ESP32 Code

/* Day 2 Project 3: Live Weather via HTTP GET */
#include <WiFi.h>
#include <HTTPClient.h>

const char* ssid = "YourSSID";
const char* password = "YourPassword";
const char* city = "Kathmandu";
unsigned long lastWeatherTime = 0;
const unsigned long weatherInterval = 30000;

String buildWeatherURL() {
  String url = "http://wttr.in/";
  url += city;
  url += "?format=%l:+%C+%t+Feels+%f+Humidity+%h";
  return url;
}

void connectToWiFi() {
  WiFi.mode(WIFI_STA);
  WiFi.begin(ssid, password);
  Serial.print("Connecting to Wi-Fi");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nConnected!");
  Serial.print("IP Address: ");
  Serial.println(WiFi.localIP());
}

void fetchWeather() {
  if (WiFi.status() != WL_CONNECTED) {
    Serial.println("Wi-Fi not connected. Cannot fetch weather.");
    return;
  }
  HTTPClient http;
  String url = buildWeatherURL();
  Serial.println("\nRequesting weather from:");
  Serial.println(url);
  http.begin(url);
  http.setTimeout(8000);
  int responseCode = http.GET();
  if (responseCode == 200) {
    String weather = http.getString();
    Serial.println("\nWeather Update");
    Serial.println("--------------------------------");
    Serial.println(weather);
    Serial.println("--------------------------------");
  } else {
    Serial.print("HTTP Error Code: ");
    Serial.println(responseCode);
  }
  http.end();
}

void setup() {
  Serial.begin(115200);
  delay(500);
  connectToWiFi();
  fetchWeather();
}

void loop() {
  if (millis() - lastWeatherTime >= weatherInterval) {
    lastWeatherTime = millis();
    fetchWeather();
  }
}

Expected Output

Weather Update
--------------------------------
Kathmandu: Partly cloudy +22°C Feels +22°C Humidity 58%
--------------------------------
API etiquette: Do not request every second. A 30-second or longer interval is better for public APIs.

Student Challenge

  • Change city to your hometown.
  • Print Weather request failed when HTTP code is not 200.
  • Add a button later to fetch weather manually.

Project 4 — ESP32 as a Web Server

Difficulty: Intermediate · Hardware: ESP32 + Wi-Fi · Duration: 35 minutes

Objective

Make the ESP32 host a small website. Any phone/laptop on the same Wi-Fi can open the ESP's IP address and view the page.

Diagram Slot 2: ESP Web Server FlowInsert diagram here: Phone/Laptop browser → Router → ESP32 IP → HTML response.

How It Works

1. ESP32 connects to Wi-Fi. 2. ESP32 starts a server on port 80. 3. Browser opens http://ESP_IP_ADDRESS. 4. ESP32 receives request. 5. ESP32 sends HTML or JSON response.

ESP32 Code: Web Server with LED Control + JSON Status

/* Day 2 Project 4: ESP32 Web Server with LED Control */
#include <WiFi.h>
#include <WebServer.h>

const char* ssid = "YourSSID";
const char* password = "YourPassword";
const int ledPin = 2;
bool ledState = false;
WebServer server(80);

String buildHomePage() {
  String statusText = ledState ? "ON" : "OFF";
  String statusColor = ledState ? "#16a34a" : "#dc2626";
  String html = "<!DOCTYPE html><html><head>";
  html += "<meta name='viewport' content='width=device-width, initial-scale=1.0'>";
  html += "<title>ESP32 Web Server</title>";
  html += "<style>body{font-family:Arial;background:#0f172a;color:white;text-align:center;padding:30px;}";
  html += ".card{max-width:420px;margin:auto;background:#1e293b;padding:25px;border-radius:18px;}";
  html += ".status{font-size:42px;font-weight:bold;color:" + statusColor + ";}";
  html += "a{display:inline-block;margin:10px;padding:12px 18px;border-radius:999px;text-decoration:none;color:white;font-weight:bold;}";
  html += ".on{background:#16a34a}.off{background:#dc2626}.api{background:#0077b6}</style></head><body>";
  html += "<div class='card'><h1>ESP32 Web Server</h1><p>Built-in LED Status</p>";
  html += "<div class='status'>" + statusText + "</div>";
  html += "<a class='on' href='/led/on'>Turn LED ON</a>";
  html += "<a class='off' href='/led/off'>Turn LED OFF</a>";
  html += "<a class='api' href='/status'>View JSON Status</a>";
  html += "</div></body></html>";
  return html;
}

void handleRoot() { server.send(200, "text/html", buildHomePage()); }
void handleLedOn() { ledState = true; digitalWrite(ledPin, HIGH); server.send(200, "text/html", buildHomePage()); }
void handleLedOff() { ledState = false; digitalWrite(ledPin, LOW); server.send(200, "text/html", buildHomePage()); }
void handleStatus() {
  String json = "{\"led\":\"";
  json += ledState ? "on" : "off";
  json += "\",\"uptime_s\":" + String(millis() / 1000) + "}";
  server.send(200, "application/json", json);
}
void handleNotFound() { server.send(404, "text/plain", "404: Page Not Found"); }

void setup() {
  Serial.begin(115200);
  pinMode(ledPin, OUTPUT);
  digitalWrite(ledPin, LOW);
  WiFi.begin(ssid, password);
  Serial.print("Connecting to Wi-Fi");
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  Serial.println("\nConnected!");
  Serial.print("Open this URL in browser: http://");
  Serial.println(WiFi.localIP());
  server.on("/", handleRoot);
  server.on("/led/on", handleLedOn);
  server.on("/led/off", handleLedOff);
  server.on("/status", handleStatus);
  server.onNotFound(handleNotFound);
  server.begin();
  Serial.println("Web server started.");
}

void loop() { server.handleClient(); }
Critical: If you forget server.handleClient() in loop(), the ESP will connect to Wi-Fi but the browser will not get a response.

Project 5 — DHT11 Interfacing and HTTP POST Data Logger

Difficulty: Intermediate · Hardware: ESP32 + DHT11 · Duration: 35 minutes

Objective

Read real temperature and humidity from DHT11 and POST the data as JSON to a test server.

Diagram Slot 3: DHT11 WiringInsert circuit diagram here: DHT11 VCC → 3.3V, DATA → GPIO4, 10kΩ pull-up DATA to VCC, GND → GND.

DHT11 Pin Configuration

DHT11 PinESP32 ConnectionESP8266 ConnectionNotes
VCC3.3V or 5V3.3VUse 3.3V for safer ESP logic.
DATAGPIO 4GPIO 4 / D2 on many NodeMCU boardsAdd 10kΩ pull-up to VCC if bare DHT11 sensor.
NCNot connectedNot connectedOnly on 4-pin bare sensor.
GNDGNDGNDCommon ground required.

ESP32 Code: DHT11 → HTTP POST JSON

/* Day 2 Project 5: DHT11 Sensor Data Logger via HTTP POST */
#include <WiFi.h>
#include <HTTPClient.h>
#include <DHT.h>
#include <ArduinoJson.h>

#define DHTPIN 4
#define DHTTYPE DHT11

const char* ssid = "YourSSID";
const char* password = "YourPassword";
const char* serverUrl = "https://httpbin.org/post";

DHT dht(DHTPIN, DHTTYPE);
unsigned long lastPostTime = 0;
const unsigned long postInterval = 10000;

void connectToWiFi() {
  WiFi.mode(WIFI_STA);
  WiFi.begin(ssid, password);
  Serial.print("Connecting to Wi-Fi");
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  Serial.println("\nConnected!");
  Serial.print("IP Address: ");
  Serial.println(WiFi.localIP());
}

void postSensorData(float temperature, float humidity) {
  if (WiFi.status() != WL_CONNECTED) {
    Serial.println("Wi-Fi disconnected. Reconnecting...");
    WiFi.reconnect();
    return;
  }
  HTTPClient http;
  http.begin(serverUrl);
  http.addHeader("Content-Type", "application/json");
  http.setTimeout(10000);
  StaticJsonDocument<256> doc;
  doc["device"] = "ESP32_DHT11";
  doc["temperature"] = temperature;
  doc["humidity"] = humidity;
  doc["unit"] = "celsius";
  doc["uptime_s"] = millis() / 1000;
  String jsonBody;
  serializeJson(doc, jsonBody);
  Serial.println("\nSending JSON:");
  Serial.println(jsonBody);
  int responseCode = http.POST(jsonBody);
  Serial.print("HTTP Response Code: ");
  Serial.println(responseCode);
  if (responseCode > 0) {
    String response = http.getString();
    Serial.println("Server response preview:");
    Serial.println(response.substring(0, 220));
  } else {
    Serial.print("POST failed. Error code: ");
    Serial.println(responseCode);
  }
  http.end();
}

void setup() {
  Serial.begin(115200);
  delay(500);
  dht.begin();
  connectToWiFi();
  Serial.println("DHT11 HTTP POST Logger Started");
}

void loop() {
  if (millis() - lastPostTime >= postInterval) {
    lastPostTime = millis();
    float temperature = dht.readTemperature();
    float humidity = dht.readHumidity();
    if (isnan(temperature) || isnan(humidity)) {
      Serial.println("ERROR: Failed to read DHT11. Check wiring and pull-up resistor.");
      return;
    }
    Serial.print("Temperature: "); Serial.print(temperature, 1);
    Serial.print(" °C | Humidity: "); Serial.print(humidity, 1); Serial.println(" %");
    postSensorData(temperature, humidity);
  }
}

Manual JSON Alternative

String jsonBody = "{\"temperature\":";
jsonBody += String(temperature, 1);
jsonBody += ",\"humidity\":";
jsonBody += String(humidity, 1);
jsonBody += "}";
DHT11 timing: Do not read DHT11 too fast. Keep at least around 2 seconds between readings.

/* Day 2 Project 6: ESP32 Live Sensor Web Dashboard */
#include <WiFi.h>
#include <WebServer.h>
#include <DHT.h>

#define DHTPIN 4
#define DHTTYPE DHT11
#define LED_PIN 2

const char* ssid = "YourSSID";
const char* password = "YourPassword";

DHT dht(DHTPIN, DHTTYPE);
WebServer server(80);

float lastTemperature = 0.0;
float lastHumidity = 0.0;
bool sensorOk = false;
unsigned long lastReadTime = 0;
const unsigned long readInterval = 2000;

String getComfortStatus(float temp, float hum) {
  if (!sensorOk) return "Sensor Error";
  if (temp > 32) return "Hot";
  if (temp < 18) return "Cold";
  if (hum > 75) return "Humid";
  return "Comfortable";
}

String buildDashboard() {
  String status = getComfortStatus(lastTemperature, lastHumidity);
  String badgeColor = sensorOk ? "#16a34a" : "#dc2626";
  String html = "<!DOCTYPE html><html><head><meta charset='UTF-8'>";
  html += "<meta name='viewport' content='width=device-width, initial-scale=1.0'>";
  html += "<meta http-equiv='refresh' content='5'>";
  html += "<title>ESP32 DHT11 Dashboard</title>";
  html += "<style>body{margin:0;font-family:Arial;background:linear-gradient(135deg,#0f172a,#123a5f);color:white;text-align:center;}";
  html += "header{padding:25px;background:#0077b6}.grid{display:flex;justify-content:center;gap:24px;flex-wrap:wrap;padding:36px 18px;}";
  html += ".card{width:230px;background:rgba(255,255,255,.1);border:1px solid rgba(255,255,255,.15);border-radius:20px;padding:24px;box-shadow:0 14px 32px rgba(0,0,0,.25);}";
  html += ".value{font-size:48px;color:#90e0ef;font-weight:bold;margin:10px 0}.label{color:#cbd5e1;text-transform:uppercase;font-size:13px;letter-spacing:1px;}";
  html += ".badge{display:inline-block;margin:10px;padding:10px 16px;border-radius:999px;font-weight:bold;background:" + badgeColor + ";}</style></head><body>";
  html += "<header><h1>ESP32 Live Sensor Dashboard</h1><p>DHT11 Temperature and Humidity Monitor</p></header>";
  html += "<div class='grid'>";
  html += "<div class='card'><div class='value'>" + String(lastTemperature, 1) + "°C</div><div class='label'>Temperature</div></div>";
  html += "<div class='card'><div class='value'>" + String(lastHumidity, 1) + "%</div><div class='label'>Humidity</div></div>";
  html += "</div><div class='badge'>" + status + "</div>";
  html += "<p>Auto-refresh every 5 seconds · JSON API: <a style='color:#90e0ef' href='/api'>/api</a></p>";
  html += "</body></html>";
  return html;
}

void readDHT11() {
  if (millis() - lastReadTime < readInterval) return;
  lastReadTime = millis();
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  if (isnan(t) || isnan(h)) {
    sensorOk = false;
    Serial.println("DHT11 read failed.");
    return;
  }
  lastTemperature = t;
  lastHumidity = h;
  sensorOk = true;
  digitalWrite(LED_PIN, HIGH); delay(40); digitalWrite(LED_PIN, LOW);
  Serial.print("Temperature: "); Serial.print(lastTemperature, 1);
  Serial.print(" °C | Humidity: "); Serial.print(lastHumidity, 1); Serial.println(" %");
}

void handleRoot() { server.send(200, "text/html", buildDashboard()); }
void handleAPI() {
  String json = "{";
  json += "\"temperature\":" + String(lastTemperature, 2);
  json += ",\"humidity\":" + String(lastHumidity, 2);
  json += ",\"sensor_ok\":" + String(sensorOk ? "true" : "false");
  json += ",\"uptime_s\":" + String(millis() / 1000);
  json += "}";
  server.send(200, "application/json", json);
}

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  dht.begin();
  WiFi.mode(WIFI_STA);
  WiFi.begin(ssid, password);
  Serial.print("Connecting to Wi-Fi");
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  Serial.println("\nConnected!");
  Serial.print("Dashboard URL: http://"); Serial.println(WiFi.localIP());
  Serial.print("API URL: http://"); Serial.print(WiFi.localIP()); Serial.println("/api");
  server.on("/", handleRoot);
  server.on("/api", handleAPI);
  server.onNotFound([](){ server.send(404, "text/plain", "404: Page Not Found"); });
  server.begin();
  Serial.println("Web server started.");
}

void loop() {
  readDHT11();
  server.handleClient();
}
Teaching warning: This project includes a tiny delay(40) only for LED blink. Do not place long delays in a web server loop, because browser requests may become slow.

Tinkercad Virtual Prototyping Activities

Tinkercad does not simulate ESP Wi-Fi, so we use it to practice sensor logic before uploading network code to real ESP boards.

Limitation: Tinkercad Circuits mainly supports Arduino UNO/Nano simulation, not ESP32/ESP8266 Wi-Fi networking. Use Tinkercad for DHT/TMP36, LDR, button, LED logic. Use real ESP32 for Wi-Fi, HTTP, APIs, and web server.

Tinkercad Activity 1 — Temperature Monitor Simulation

Use TMP36 in Tinkercad as a simple temperature-sensor approximation before DHT11 hardware.

Create a new Tinkercad circuit.
Add Arduino UNO.
Add TMP36 temperature sensor.
Wire TMP36 +V to 5V, GND to GND, OUT to A0.
Add LED on pin 9 through 220Ω resistor to GND.
Open Code → Text mode → paste the code → Start Simulation.
/* Tinkercad Activity 1: Temperature Monitor using TMP36 and LED */
const int SENSOR_PIN = A0;
const int LED_PIN = 9;
const float ALERT_TEMP = 30.0;

void setup() {
  Serial.begin(9600);
  pinMode(LED_PIN, OUTPUT);
  Serial.println("=== Temperature Monitor Started ===");
}

float readTempC() {
  int raw = analogRead(SENSOR_PIN);
  float voltage = raw * (5.0 / 1023.0);
  float tempC = (voltage - 0.5) * 100.0;
  return tempC;
}

void loop() {
  float temp = readTempC();
  Serial.print("Temperature: ");
  Serial.print(temp, 1);
  Serial.println(" C");
  if (temp > ALERT_TEMP) {
    digitalWrite(LED_PIN, HIGH);
    Serial.println("ALERT: High temperature!");
  } else {
    digitalWrite(LED_PIN, LOW);
  }
  delay(1000);
}

Simulate a multi-sensor IoT node using temperature, LDR, pushbutton, and LEDs.

/* Tinkercad Activity 2: Multi-Sensor Dashboard Simulation */
const int TEMP_PIN = A0;
const int LDR_PIN = A1;
const int BUTTON_PIN = 7;
const int RED_LED = 13;
const int GREEN_LED = 12;
int lastButtonState = LOW;

void setup() {
  Serial.begin(9600);
  pinMode(RED_LED, OUTPUT);
  pinMode(GREEN_LED, OUTPUT);
  pinMode(BUTTON_PIN, INPUT);
  Serial.println("Multi-Sensor Monitor Ready");
  Serial.println("Press button for instant reading");
}

float readTempC() {
  float voltage = analogRead(TEMP_PIN) * (5.0 / 1023.0);
  return (voltage - 0.5) * 100.0;
}

String getLightLevel(int raw) {
  if (raw < 200) return "DARK";
  if (raw < 600) return "DIM";
  return "BRIGHT";
}

void printSensorData() {
  float temp = readTempC();
  int ldrRaw = analogRead(LDR_PIN);
  String light = getLightLevel(ldrRaw);
  Serial.println("--- Sensor Reading ---");
  Serial.print("Temperature: "); Serial.print(temp, 1); Serial.println(" C");
  Serial.print("Light Raw: "); Serial.println(ldrRaw);
  Serial.print("Light Level: "); Serial.println(light);
  Serial.print("[JSON]: ");
  Serial.println("{\"temp\":" + String(temp, 1) + ",\"light\":\"" + light + "\"}");
  if (temp > 28.0) {
    digitalWrite(RED_LED, HIGH);
    digitalWrite(GREEN_LED, LOW);
  } else {
    digitalWrite(RED_LED, LOW);
    digitalWrite(GREEN_LED, HIGH);
  }
}

void loop() {
  int buttonState = digitalRead(BUTTON_PIN);
  if (buttonState == HIGH && lastButtonState == LOW) {
    Serial.println(">>> BUTTON PRESSED — Manual Read!");
    printSensorData();
  }
  lastButtonState = buttonState;
  static unsigned long lastTime = 0;
  if (millis() - lastTime >= 5000) {
    printSensorData();
    lastTime = millis();
  }
}

Testing with Browser and Postman

Use these tests to prove that the ESP server/API is working correctly.

Browser Tests

  • Open http://ESP_IP/ to view dashboard.
  • Open http://ESP_IP/api to view JSON data.
  • Open http://ESP_IP/led/on to control LED.
  • Open http://ESP_IP/led/off to turn LED off.

Postman Tests

  • Select GET and enter http://ESP_IP/api.
  • Click Send and check status code 200.
  • For POST tests, choose Body → raw → JSON.
  • Check status code, response body, and returned JSON.

Assignments & Challenges

Use these as group tasks, homework, or practical evaluation.

Assignment 1 — Wi-Fi Reconnect Logic

  • Connect to Wi-Fi and print IP address.
  • Check WiFi.status() every 5 seconds.
  • If disconnected, print warning and call WiFi.reconnect().
  • Bonus: print uptime in seconds.

Assignment 2 — HTTP GET JSON Parse

  • Fetch https://jsonplaceholder.typicode.com/todos/1.
  • Use ArduinoJson to parse response.
  • Print userId, id, title, and completed.
  • Bonus: fetch /users/1 and extract name, email, city.

Assignment 3 — Web Server LED Control

  • Create routes /, /led/on, /led/off, /status.
  • Use GPIO 5 with LED and 220Ω resistor.
  • /status returns {"led":"on"} or {"led":"off"}.
  • Bonus: style page with green/red status indicator.

Assignment 4 — Environment Monitor Dashboard

  • Read DHT11 on GPIO 4.
  • Host live dashboard at /.
  • Return JSON at /api/data with temp, humidity, uptime.
  • POST reading to httpbin every 60 seconds.
  • Bonus: add heat index calculation.
