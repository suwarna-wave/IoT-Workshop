1. What is IoT?

IoT means Internet of Things. It is any physical object that can sense, process, communicate, or respond.

Real-World Examples

Normal Device IoT Version
DustbinSmart bin that detects fill level
Door lockRFID door lock
Light bulbSmart light controlled by phone
Water tapTouchless smart tap
Parking spaceSmart parking system
Farm fieldSmart irrigation system

Smart Temperature Flow

Temperature sensor reads room temperature → ESP32 processes the reading → Wi-Fi sends the data → Dashboard displays the value → Fan or AC responds

2. Basic IoT Architecture

Most IoT systems follow the same flow from the physical world to user action.

[Physical World] ↓ [Sensors / Actuators] ↓ [Microcontroller] ↓ [Communication Network] ↓ [Cloud / Server / Dashboard] ↓ [User / Automation / Alert]

Sensor

Reads real-world data. Examples: DHT11, LDR, MQ-2, ultrasonic.

Actuator

Performs action. Examples: LED, buzzer, relay, servo motor.

Dashboard

Visual display and control layer for web or mobile applications.

Critical rule

Every circuit must have a common GND. Without common ground, the signal may not be read correctly.

4. Understanding Signal Types

Different signals represent data in different ways. This is fundamental for IoT work.

Digital Signal

Only two states: HIGH/LOW, ON/OFF, 1/0.

Button pressed = HIGH LED OFF = LOW

Analog Signal

Changes smoothly and can have many values. Arduino UNO reads 0 to 1023.

LDR Potentiometer Temperature

PWM Signal

Used to control brightness or speed by switching ON and OFF very fast.

analogWrite(pin, value);  // 0 to 255

GPIO

General Purpose Input Output. Most usable pins on Arduino and ESP boards are GPIO pins.

pinMode(pin, INPUT);
pinMode(pin, OUTPUT);

5. IoT Communication Protocols

A protocol is a set of rules for how devices communicate with each other.

Network Protocols

  • HTTP - send and request data from web servers
  • MQTT - lightweight publish/subscribe messaging
  • WebSocket - live dashboard updates
  • ESP-NOW - direct ESP-to-ESP communication
  • Bluetooth - phone-to-device communication

Hardware Protocols

  • UART - TX and RX communication
  • I2C - SDA and SCL communication
  • SPI - faster communication with SS, MOSI, MISO, SCK
  • One-Wire - single data wire for some sensors

5A. Day 0 Recap

A quick review section with dropdown FAQs so students can revisit the core ideas before moving on.

What is the main idea of IoT?

IoT is the combination of sensing, processing, communication, and action. A device becomes smart when it can read the environment, decide what to do, communicate that data, and respond.

Why do we start with Arduino before ESP32?

Arduino gives students a cleaner entry into pins, circuits, and control flow. Once those ideas are stable, ESP32 and ESP8266 add Wi-Fi and make the same skills useful for connected systems.

What should I remember about digital, analog, and PWM signals?

Digital signals have two states, analog signals change gradually, and PWM is a fast switching technique used to simulate variable output such as dimming an LED or controlling motor speed.

What is the one rule that prevents many wiring mistakes?

Always share a common ground between the board and the components. If the ground is missing, signals often become unreliable even when the code is correct.

6. Arduino IDE Setup

Arduino IDE is the software where you write and upload code to your board.

Required Software

  • Arduino IDE 2.x
  • USB driver
  • ESP32 board package
  • ESP8266 board package

Arduino UNO Steps

  1. Open Arduino IDE.
  2. Connect Arduino UNO using USB.
  3. Select Tools → Board → Arduino Uno.
  4. Select Tools → Port → COMx.

ESP32 Steps

  1. Open Preferences.
  2. Add ESP32 board manager URL.
  3. Install the board package.
  4. Select ESP32 Dev Module.

7. First Code: Blink Programs

Start with the built-in LED on Arduino UNO, then move to an external LED and ESP boards.

Arduino UNO Built-in LED

Built-in LED location

The Arduino UNO built-in LED is connected to pin D13.

const int builtInLedPin = 13;

void setup() {
  pinMode(builtInLedPin, OUTPUT);
}

void loop() {
  digitalWrite(builtInLedPin, HIGH);
  delay(1000);
  digitalWrite(builtInLedPin, LOW);
  delay(1000);
}

External LED Blink

LED PartConnect To
Long leg / AnodeD8 through 220Ω resistor
Short leg / CathodeGND
 
const int ledPin = 8;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}
LED safety

Always use a resistor with an LED. Without it, the LED or the board pin can be damaged.

8. Serial Monitor Debugging

Serial output helps you understand what the board is doing while your code runs.

const int ledPin = 8;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
  Serial.println("Arduino LED Blink Program Started");
}

void loop() {
  digitalWrite(ledPin, HIGH);
  Serial.println("LED is ON");
  delay(1000);

  digitalWrite(ledPin, LOW);
  Serial.println("LED is OFF");
  delay(1000);
}

Serial Monitor setting: Baud rate 9600 for Arduino UNO. Use the same baud rate in the monitor and in code.

9. Moving from Arduino to ESP

Arduino teaches electronics control. ESP32 and ESP8266 add Wi-Fi and make the project IoT-ready.

ESP32

Recommended for most workshop labs because it has Wi-Fi, Bluetooth, more GPIOs, and strong IoT support.

ESP8266

Good Wi-Fi board with fewer pins. Useful for low-cost IoT examples.

ESP32 Blink

const int ledPin = 2;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(115200);
  Serial.println("ESP32 LED Blink Program Started");
}

void loop() {
  digitalWrite(ledPin, HIGH);
  Serial.println("ESP32 LED is ON");
  delay(1000);
  digitalWrite(ledPin, LOW);
  Serial.println("ESP32 LED is OFF");
  delay(1000);
}

ESP8266 Blink

Active LOW note

Many ESP8266 built-in LEDs work in reverse: LOW turns the LED ON and HIGH turns it OFF.

const int ledPin = LED_BUILTIN;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(115200);
}

void loop() {
  digitalWrite(ledPin, LOW);
  delay(1000);
  digitalWrite(ledPin, HIGH);
  delay(1000);
}

10. Important Pin Safety

Some pins are safer for beginners than others. Use these as your default starting points.

ESP32 safer GPIO pins

GPIO 4, 5, 16, 17, 18, 19, 21, 22, 23, 25, 26, 27, 32, 33

Avoid or use carefully

ESP32: GPIO 0, 2, 12, 15. ESP8266: D0, RX, TX for normal beginner circuits.
